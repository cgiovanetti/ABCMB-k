2026-10-29) is in the tag pre-trim-2026-11-06 (= e2609d2): git show pre-trim-2026-11-06:CHANGELOG.txt.

2026-11-09 — Bounds and one-sided intervals back (and extended); convergence is the stop
---------------------------------------------------------------------------------------
- Restored from the pre-trim driver (the review trim 9a2e1f6 cut them): config `bounds` (hard optimizer
  limits, POI grids inside them) and the boundary-aware thresholds of Cowan, Cranmer, Gross & Vitells (t~,
  the Feldman-Cousins ordering in the Gaussian limit), so an interval next to a bound is two-sided or a
  one-sided limit as the data decide; threshold curves and bounds in the png.
- New: config `box` (per-parameter optimizer box, scaled sigmas). A row on a box face converges when chi2 is
  flat outward (slope < GTOL), and is held by the box (at_box, not converged) only while chi2 still falls;
  before, any row at +-XBOX was unconverged, so an open nuisance direction (a decoupling mass) failed. Each
  interval end is a crossing, the bound or open; kinds two-sided / upper / lower limit / unconstrained (npz
  ends*, kind*, log). A POI grid crossing a bound is shifted onto it, width kept. pchip instead of the quartic
  for a profile still falling at a non-bound grid end (the quartic invented a turn-over, 0.02 off on the toy).
  compare_profile_runs.py draws bounds, skips the parabola for bounded / one-sided panels, and takes pinned
  rows from the npz at_box.
- Stop: lm_rows logs and returns why it ended (converged / sigtol / maxit; npz stop_reason). PA_SIGTOL
  default 1e-2 -> 0: convergence is the stop. Interval stability dates from the BFGS era (06-23), when
  gradients floored at |g| ~ 2 and rows never converged; every run since _v3 converged (_v6bbn: two ranks
  stopped on stability with every row already converged, two on convergence, none at MAXIT). It stays as an
  option for a likelihood too rough for rows to converge or stall.
- Tests: pytests/test_profile_bounds.py on configs/toy_bounded.py against closed forms (upper limits 1.000 /
  1.960 for a best fit on the bound, the shorter limit for one outside, lower limit / unconstrained for an
  open POI, a flat vs a falling box face); CPU 17/17 in either file order. On the stored _v6bbn profiles the
  new interval code reproduces every interval exactly, all two-sided.

2026-11-07 — "recomb" lna grid replaces the frozen grid; exact visibility derivative (branch lna-grid)
-----------------------------------------------------------------------------------------------------
- Why Cl(theta) was jagged in the node positions (the reason for the frozen grid): the Doppler source's
  g' = grad(visibility) went through the finite-difference-slope cubic of exp(-kappa), an error pattern with
  the table's period. Shifting every node by delta at fixed cosmology: low-l TT ripple 1.3e-3 (8.5e-7 with
  the Doppler term off).
- abcmb/ (every grid mode): Hermite tau and exp(-kappa) lookups with exact slopes 1/aH and
  exp(-kappa)/(tau_c aH); g' = Background.visibility_prime = exp(-kappa)/tau_c [1/(tau_c aH) - tau_c'/tau_c].
  Ripple 1.3e-3 -> 3e-6 at low-l TT, 3e-8 at l > 500.
- Rejected: the Doppler term integrated by parts onto j_l' (needs no g' or theta_b'; ripple 7e-9) is 2-6% off
  CLASS in TT at 300 nodes: k g V j_l' in the post-recombination tail cancels only on a dense grid.
- lna_grid_mode="recomb" (perturbations.py): a base grid from physics constants (floor + Gaussian at
  mu0 = -6.99, width 0.31, on [-7.7, 0]) whose core shifts by mu - mu0 (mu = the visibility-per-lna mean on a
  fixed lattice) through a cosine window; LoS weights are the map's exact Jacobian. Knobs lna_recomb_<name>.
- Accuracy over a profile's range (P0, omega_b +-3.8e-4, Neff 2.6 / 3.5) vs a 2400-node uniform grid: recomb
  TT 2.6e-4 (l < 500), 2e-5 (l > 500), TE/EE 1e-5 (l > 30); the frozen grid TT 2-4e-4, TE/EE 1-2e-4. Low-l
  TE/EE 1.5e-3 on both (reionization, as on the visibility grid). Vs CLASS 3.3.4 with delta_l_max matched:
  TT <= 8.8e-4 everywhere (main: 2.7e-3 at l < 30, the old 300-node low-l bias).
- AD along omega_b / Neff over +-0.5 sigma (v - v0 - int AD): max|R| 3e-6 / 1.3e-6 at l < 30 TT, <= 9e-7
  elsewhere; AD roughness 2% / 0.5% of the low-l TT slope per sigma, ~1e-4 at l >= 100. The frozen grid on
  the same code: max|R| 4.4e-6 at l < 30 TT (the value floor is HyRex's, as before) but smoother tangents
  (roughness 5.5e-9 vs 5.6e-6 at l < 30, 6e-8 vs 1.2e-6 at l 30-99): moving nodes see x_e' (a Catmull-Rom
  table of HyRex output) through g'. Exact x_e' would need HyRex's own derivative; not done.
- Cost: the same as the frozen grid (B = 8 on one A100, compiled: values 148.7 vs 148.2 s, staged gradient

Method decisions and rejected alternatives (2026-10-11 to 10-29)
----------------------------------------------------------------
- Optimizer (a21df86, 10-19): Levenberg-Marquardt on each row's Gauss-Newton matrix J^T W J from forward-mode
  AD C_ell tangents (plik residual and covariance, plik nuisances through the Schur complement, exact low-ell
  Hessian), AD only. Removed with it: the lockstep BFGS, the FD warm Hessian and FD nuisance Hessian, the FD
  gradient fallback and the FD-on-batch gradient. Reasons: FD warm Hessians came out indefinite and wrecked
  the July-September Neff profiles; BFGS updates bought nothing (10-08 A/B: same intervals, the fixed
  Hessian converged in fewer iterations); a gradient-free batched minimizer needs values ~30-45x cheaper than
  a gradient (the fork's were ~20x).
- Multimodality (c501307, 10-19; 844d787, 10-22): spread starts along the softest GN directions, flags,
  branches from every distinct spread-start minimum, lower envelope, union-of-regions intervals; tested end to
  end on a toy bimodal profile (pytests/test_profile_toy.py). Deflated Newton walks (Farrell, Birkisson &
  Funke 2015) were added and then removed: they find saddles as well as minima, add no certainty beyond the
  spread starts, and only ever triggered on noise. Rejected by the user: neighbour cross-seeding, SMC
  seeding, NeuTra.
- Frozen lna grid (4353aa1, 10-16): the save / line-of-sight grid is built once at the config centre
  (Model.freeze_lna_grid). The visibility grid moved every node with theta, so the Cls were jagged and the
  per-ell AD tangents wrong (omega_b TT AD vs FD 0.38 -> 9.6e-3), at no cost; a stop_gradient on the moving
  grid made it worse (0.38 -> 0.74).
- Debye j_l (db4f265, 10-16): large-x spherical Bessel functions through u_3; the table-to-asymptotic switch
  jump 3.75e-5 -> 7e-8 of max|j_l|, the high-l AD bias along omega_cdm at l=2500 -6.0e-6 -> -0.52e-6 of Cl.
- Engine smoothness (xe-c1, 10-11/12; bd34849): C^1 x_e lookup and continuous lna_transfer_start / lna_rec
  (the Cl step that trapped the v2 rows), C^1 j_l lookups and Tsit5 for the optical depth (AD = FD on the
  production path, no timing cost).
- dtmax_PE = 0.03 for k < 0.06 (b9dfcc3, 10-15): low-ell TT interpolation error 2.6e-3 -> 3e-7 for +3.3%
  value time. It replaces step_ts (stepping onto the save grid): +12.9% time and an AD bug.
- Gradient path (10-14): directions vmapped inside each staged jvp (one primal solve per gradient, ~5x),
  output table built per k-chunk, spectrum stage sub-batched (PA_GRAD_SPECB=4), HyRex jvp on a host-device
  mesh (PA_CPU_DEVICES=16). Evaluated and not adopted: GRADSOLVE (no faster), modax (values ~10x cheaper, its
  sensitivities only ~1.5x on the gradient, and a port of the hierarchy would be needed).
- LINX stage (5146ffd, 10-20): the driver runs LINX for all rows at once on one host device (vmapped, chunks
  of 64) and feeds the engine YHe / Neff / T_nu plus their Jacobian by the chain rule. No Mesh sharding (the
  ODE loops' batch-wide stop test becomes a cross-device all-reduce per step and times out), no pmap (lineax's
  linear_solve primitive), no jax.jacfwd (a zero tangent through the background solve gives NaN). The
  Jacobian ran one cosmology at a time until the dense grid; since 27d5397 it is one batched two-jvp program
  with a per-lane fallback (64/64 finite, 1.25 s per row vs 5.7).
- Dense-grid log-log LINX (27d5397, 10-22): the vendored background outputs n_out = 4096 log-spaced times
  read from the dense interpolant and the network interpolates log-log, so YHe roughness along
